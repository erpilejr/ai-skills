# Agent instructions

These apply to any agent working with me, in this repo or anywhere these instructions are loaded.

## Instructions for me: always give the direct link

When you tell me to do something myself (configuration, setup, creating a key or token, a manual step in a
runbook), make every place I have to go one click away:

- **A website:** the direct `https://` URL of the exact page, not the site's home page. For example, the GitHub
  fine-grained token page is https://github.com/settings/personal-access-tokens/new, not "GitHub settings".
- **A local file:** its absolute path, for example `/Users/ernestopillejr/projects/<repo>/.env`, written as a
  Markdown link where the app renders links.
- **A command:** in its own fenced code block, ready to copy.

If you don't know the exact URL, say so and give the closest page you're sure of. Never make me search for where
to go.
